# Anexos-Secundarios-TFG
En este repositorio se guardan las tablas con los controles de las normas utilizadas, junto a sus explicaciones breves, en la carpeta "Controles"; y las evidencias del análisis de auditoría de las aplicaciones analizadas en el documento .pdf "Análisis de aplicaciones TFG". Además, también se facilita el código fuente de la herramienta web desarrollada, en el archivo "Herramienta_web.html"; y el documento de demostración de la validación externa en el documento "Validación_Externa.pdf".
